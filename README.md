# CriAr

Gestión de cría de caballos de polo: caballos y pedigrí, actividad, sanidad, dinero, categorías y lotes, alertas y equipo.

**Abrir la app:** https://smignaquy.github.io/criar/

La app es un solo archivo (`index.html`) y guarda los datos en el navegador de cada dispositivo.
Las cuentas están en **modo prueba**: viven en ese navegador y el código por SMS se muestra en pantalla,
hasta que se conecte un servidor.

`codigo/` tiene el código de cuentas, roles y equipo, el script que lo integra a la app y las pruebas.
